For each subagent dispatch:

1. **Pre-dispatch:** confirm task scope and file ownership
2. **Subagent executes:** writes/edits files, runs shellcheck, runs smoke test (if any), commits
3. **Stage 1 review (you):** read the diff (`git show HEAD`), verify it matches plan
4. **Stage 2 review (you):** run any verification commands the task specified (smoke test, shellcheck on adjacent files, etc.)
5. **If green:** dispatch next task. **If red:** dispatch a fix subagent or fix inline.
