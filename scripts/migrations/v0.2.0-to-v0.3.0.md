# Migration v0.2.0 → v0.3.0

## What the bash script does (deterministic)

- Adds `vault_path: /absolute/path` to `wiki.config.md` (after `vault_name:` line) if missing
- Skips if `vault_path:` already present (idempotent)

## What the agent does after the script (intelligent)

1. **Verify vault_path** — confirm the inserted `vault_path` resolves to the actual vault directory on disk. Correct it if the script's working directory differed from the vault root.

2. **Validate** — run `$PLUGIN_ROOT/scripts/wiki-health.sh` to confirm no regressions.

3. **Update schema_version** — set `schema_version: "0.3.0"` in `wiki.config.md` after successful validation.

## Schema changes in v0.3.0

### New required field in wiki.config.md
- `vault_path: /absolute/path` — absolute path to vault root, used by all bash scripts. Complements `vault_name:` which is used by the obsidian CLI.

### No wiki page schema changes
- All wiki page frontmatter fields remain the same as v0.2.0.
