# Migration v0.1.0 → v0.2.0

## What the bash script does (deterministic)

- Adds `confidence:` field based on sources count (1→low, 2→medium, 3+→high)
- Adds `relations: []` placeholder to all wiki pages
- Computes `source_hashes:` via `shasum -a 256` for each raw source referenced

## What the agent does after the script (intelligent)

1. **Verify confidence levels** — for pages marked `medium` or `high` by the script (based on source count), verify the sources actually corroborate (not just repeat) the claims. Downgrade to `low` if sources are duplicates or derivatives of the same original.

2. **Add contradiction relations** — for pages with `> [!warning]` callouts, determine if a `contradicts` relation can be identified and add it to `relations:` frontmatter.

3. **Validate** — run `$PLUGIN_ROOT/scripts/wiki-health.sh` to check for regressions introduced by migration.

4. **Update schema_version** — set `schema_version: "0.2.0"` in `wiki.config.md` after successful migration.

## Schema changes in v0.2.0

### New required frontmatter fields
- `confidence: low|medium|high` — epistemic scoring based on source corroboration
- `relations: []` — typed entity relations (contradicts, supports, is-a, part-of, evolved_into, depends_on)

### New optional frontmatter fields
- `source_hashes:` — SHA-256 hashes of raw source files for drift detection

### New page sections
- `## Counter-Arguments & Gaps` — required for concept pages, optional for others

### New operations
- **Reflect step** in ingest — auto-creates decision records when contradictions arise
- **Session handoff** in log — Deferred/Next fields for session continuity
- **Search-first query** — wiki-search.sh as primary path, never load index.md
- **L0-L3 progressive disclosure** — triage at L0 (tldr), drill at L2 (full page)
